# Security policy

This repository holds the source of a static personal website (no server, no
database, no accounts, no forms that submit anywhere).

## Reporting a vulnerability

Please report security issues privately through GitHub:
**[Report a vulnerability](https://github.com/Stephen-Carras/stephen-carras.github.io/security/advisories/new)**
(Security tab → "Report a vulnerability"). Please do not open a public issue.

Helpful details: the affected URL or file, steps to reproduce, and the impact you
expect. You should hear back within a few business days.

The same contact is published at `/.well-known/security.txt` on the live site.

## Scope

In scope: the site's HTML, CSS and JavaScript, its Content Security Policy, and this
repository's build and deploy workflows.

Out of scope: GitHub Pages itself and its response headers (report those to GitHub),
and third-party sites the pages link to (for example LinkedIn).

## Supported versions

Only the version currently deployed from `main` is supported.
